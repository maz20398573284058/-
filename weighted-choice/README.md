# weighted-choice: нормалізація та зважений рейтинг

Навчальний проєкт: прозорий рейтинг альтернатив з різними одиницями вимірювання
(min-max нормалізація за напрямом критерію + зважена сума). Рейтинг зберігає
вихідні дані, перетворення й ваги, а обов'язкові обмеження перевіряються **до** суми.

## ⚠️ Використання ШІ

Цей проєкт створено за допомогою **Claude (Anthropic)**. Claude згенерував код,
тести, набір навчальних даних і текст цього README за описом завдання.

- Дані в `data/` **вигадані для навчальної демонстрації**; реальних джерел немає.
  Перед використанням для справжнього рішення їх треба замінити й вказати джерела.
- Код і результати я запускав і перевіряв локально; відповідальність за роботу
  та її розуміння лежить на мені, як на авторі.

## Вимоги та запуск

Python 3.11+, лише стандартна бібліотека.

```bash
python demo.py                          # демонстраційний приклад (3 майданчики)
python main.py                          # власний рейтинг за даними з data/
python -m unittest discover -s tests -v # тести
```

## Паспорт рішення

**Мета:** обрати майданчик для навчального семінару.

| Критерій | Одиниці | Напрям | Вага | Обґрунтування ваги |
|---|---|---|---|---|
| Вартість оренди | грн/день | витрати | 0.45 | бюджет обмежений |
| Місткість | місць | вигода | 0.25 | запас місць для гостей |
| Відстань до університету | км | витрати | 0.30 | менше часу на дорогу |

**Обмеження (перевіряються до рейтингу):** місткість ≥ 30 місць; вартість ≤ 6000 грн/день.
Відсіяно: «Коворкінг Центр» (6500 грн) та «Мала аудиторія» (25 місць).

**Формули.** Вигода: `(x − min)/(max − min)`, витрати: `(max − x)/(max − min)`,
підсумок `S_i = Σ w_j · r_ij`. Min/max беруться по **допустимих** варіантах,
тому відсіяні альтернативи шкалу не змінюють.

| 3 | Аудиторія коледжу | 0.5230 | 0.3667, 0.0278, 0.1286 |

### Ручний розрахунок («Актова зала школи»)

Допустимі значення: cost 2500–5200 (діапазон 2700), capacity 35–80 (45), distance 0.5–4.0 (3.5).

- cost: (5200 − 2500)/2700 = **1.0**, внесок 0.45 · 1.0 = 0.45
- capacity: (80 − 35)/45 = **1.0**, внесок 0.25 · 1.0 = 0.25
- distance: (4.0 − 4.0)/3.5 = **0.0**, внесок 0.30 · 0 = 0
- Сума: 0.45 + 0.25 + 0 = **0.70** ✔ (збігається з виводом програми)

Демо-приклад, альтернатива A: ціна (500−400)/200 = 0.5, доступність (8−6)/4 = 0.5,
S = 0.4·0.5 + 0.6·0.5 = **0.5**.

### Інтерпретація

- Переможець виграє завдяки вартості (+0.33 до внеску порівняно з другим місцем)
  і місткості (+0.11), але програє за відстанню (−0.27): це найдальший варіант.
- Відрив від 2-го місця 0.17, а 2-е й 3-є місця розділяє лише 0.007, це майже нічия,
  тож їхній порядок не слід трактувати категорично.

### Додатково: фіксовані зовнішні межі

Якщо нормалізувати за зовнішніми межами (cost 1000–8000, capacity 20–100, distance 0–5)
замість min/max набору, переможець **змінюється**: «Конференц-зал бібліотеки» 0.6020
проти «Актова зала школи» 0.6011. Тобто результат залежить від вибору шкали
й підсумковий бал має сенс лише разом зі шкалою та набором варіантів.

## Погоджені правила

- **Сталий критерій** (max == min): усі отримують оцінку 1. Це не змінює різницю між підсумками.
- **Нічия:** не ховається вибором першого елемента; однакові бали (допуск 1e-9) отримують
  однакове місце з позначкою `=` (наприклад `1=`).
- **Некоректні дані:** NaN/∞, нечислові значення, неправильна довжина рядка, відʼємні ваги
  та сума ваг ≠ 1 відхиляються з повідомленням про конкретний критерій або рядок.
- **Проміжні результати не округлюються** до завершення підсумовування.

## Що покривають тести

Звичайний сценарій (демо), помилковий напрям (порядок той самий, але бали 1.0 / 0.5 / 0.0),
сталий стовпець, неправильна сума ваг, відʼємна вага, NaN та ∞, дубль альтернативи
(однакові бали), представлення нічиєї, зміна одного критерію (змінюється лише його внесок),
вплив крайнього значення на шкалу, відбір за обмеженнями, перенормування ваг, фіксовані межі.

## Що потрібно уточнити перед реальним рішенням

Реальні ціни, місткість і відстані з джерелами; узгоджені ваги (наприклад, експертна
оцінка); чи не потрібні додаткові обов'язкові обмеження (доступність, обладнання).
